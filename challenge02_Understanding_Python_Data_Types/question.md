# Your challenge
Python Challenge 002
Difficulty: Beginner
Estimated: 15–20 minutes

## Task: Build a Student Information Analyzer.

Write a Python program that:
1. Creates a variable student_name containing your name.
2. Creates student_age containing your age.
3. Creates student_height containing a decimal number.
4. Creates is_learning_python containing True.
5. Prints all four variable values.
6. Uses type() to display the data type of each variable.

Bonus challenge:

Create another variable called graduation_year containing a whole number and display its data type.

### Expected output format
Student Name: Christopher
Student Age: 25
Student Height: 1.75
Learning Python: True

### Data Types:
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>
