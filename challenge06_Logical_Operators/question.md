# Tasks
Write Python code to determine:
1. Is the user at least 18 years old?
2. Is the user registered AND has a valid ID?
3. Is the user registered OR has a valid ID?
4. Is the user NOT registered?
5. Is the user eligible for access? (Must be at least 18, registered, and have a valid ID.)
Display each result using f-strings.
## Expected output
===== ACCESS ELIGIBILITY CHECK =====

Is the user at least 18? True
Is the user registered and has valid ID? True
Is the user registered or has valid ID? True
Is the user not registered? False
Is the user eligible for access? True

===================================


## Bonus challenge
Change the variables to:
age = 16
is_registered = True
has_valid_id = False



Without changing your logic, run the program again and observe how the results change.

This is important: good programs use logic that adapts to changing data instead of hardcoding answers.
